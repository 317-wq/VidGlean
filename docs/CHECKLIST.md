# 开发清单

对应 PRD V1.1 的第一版范围。已完成打勾，未完成或待验证留空。

## 功能

- [x] Bilibili 视频链接导入（视频页链接、b23.tv 短链、BV 号）
- [x] 链接解析预览（封面、标题、UP 主、时长、类型、重复检测）
- [x] 字幕获取（优先中文 CC 字幕；无字幕与凭证失效分开提示）
- [x] AI 总结生成（三档深度、类型化结构、额外要求）
- [x] 长字幕分段提炼（超长字幕先分段要点再合并）
- [x] Markdown 模板管理（内置 3 套、上传校验、默认模板）
- [x] Markdown 阅读（后端渲染、代码高亮、公式、表格）
- [x] Markdown 源码编辑（防抖自动保存、Ctrl+S）
- [x] 版本回退（编辑或重新生成前的版本可恢复）
- [x] 文档分类、标签（AI 自动生成）、星标
- [x] 全文搜索（中文二元分词 + FTS5）
- [x] 文档专属 AI 对话（流式、上下文隔离、清空）
- [x] AI 辅助修改（diff 预览 + 确认应用）
- [x] AI 模型配置（多模型、连通性测试、切换当前）
- [x] B 站凭证管理（系统凭据管理器）
- [x] 任务管理（四阶段、失败续跑、暂停/继续/取消）
- [x] 并发限制与指数退避重试
- [x] 任务进度推送（SSE）
- [x] 本地数据存储（Markdown 文件为真源、SQLite 索引）
- [x] 备份、加密备份与恢复
- [x] 数据目录迁移
- [x] 临时文件清理
- [x] 日志轮转、脱敏、导出、过期清理
- [x] 三套主题（浅色 / 深色 / 柔和蓝粉紫）
- [x] 快捷键（Ctrl+F / Ctrl+N / Ctrl+S / Esc）
- [x] 启动页与后端初始化状态
